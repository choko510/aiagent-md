# SCIP consumer (DEV-13 B1)

`scip.proto` is from [scip-code/scip](https://github.com/scip-code/scip/blob/be1d9f769a02a11be3b3ec5485231e2531a78a1c/scip.proto), commit `be1d9f769a02a11be3b3ec5485231e2531a78a1c`, Apache-2.0; its license is `SCIP-LICENSE.txt`. `scip_pb2.py` was generated from that schema with grpcio-tools 1.78.0 / protoc 6.31.1 and formatted with Ruff. The Python runtime dependency is protobuf 6.33.6 in `uv.lock` (BSD-3-Clause). The [protobuf security advisories](https://github.com/protocolbuffers/protobuf/security/advisories) were checked on 2026-11-16; 6.33.6 is above the fixed versions for GHSA-8qvm-5x2c-j2w7. The binary parsing library still requires isolation and resource limits.

`IndexManifest` and `SourceProvenance` must come from an authorized, trusted integration. They bind tenant, owner, repository, revision, tree, blob IDs, source hashes, index hash, and claimed indexer identity. `VALIDATED` indicates structural and snapshot checks only: the indexer, its behavior, its execution evidence and any toolchain digest are **not authenticated or verified** by this library. SCIP itself does not prove which source generated the index. `coverage` remains UNKNOWN, and PRECISE_INDEX_REPORTED means the relationship was reported by the index, not independently proved. Never use a manifest supplied by the model as authorization. The index's `project_root`, documentation, source text and diagnostic strings are never used as host paths or returned as instructions.

If dependency lockfiles exist, absence of a lock digest yields PARTIAL. The optional fingerprint is SHA-256 over the domain `DEV13-locks-v1\0`, followed by each tracked lock path, blob ID and SHA-256 content digest in sorted path order; each field is prefixed by its four-byte big-endian length. A mismatch is STALE. Toolchain and execution evidence remain unverified caller claims.

`load_index` processes at most 4 MiB of SCIP input in a separate Linux process with 256 MiB address-space, five CPU seconds, an output cap and caller deadline; Windows and other operating systems return UNAVAILABLE. These limits are not a VM, egress filter or tenant boundary. Production deployment requires the existing untrusted Cell and externally enforced network/filesystem isolation. The source must be UTF-8 without BOM; UTF-8/UTF-16/UTF-32 **position units** are supported. Unknown indexer position encoding is accepted only for ASCII documents, where all units coincide, and yields PARTIAL. A mismatch or uncertain range is never repaired silently. Reference relationships are followed within this index; `is_definition` relationships are not interpreted and force PARTIAL with text fallback. Use `navigate` for same-snapshot text fallback; scope mismatches raise and never fall back across repositories. Source snippets are not returned.

The actual synthetic Python index fixture was produced using scip-python 0.6.8 (MIT); see the test fixture README for its command. TypeScript and Rust indexers, runtime execution evidence, cross-repository identity reconciliation, incremental indexes and production integration are not verified here. Do not use the graph to authorize edits or bypass required review or tests.
