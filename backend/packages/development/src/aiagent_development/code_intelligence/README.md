# Code Intelligence Slice A

This independent diagnostic library accepts a snapshot and Git executable selected by a **trusted caller**. `AuthorizedSnapshot` is a carrier, not an authorization token. Do not expose a path-taking API to model input. Deploy only in an isolated execution cell with a stable, read-only repository and externally enforced process, filesystem and network isolation. Repository metadata must not change while the reader is alive; metadata checks are not race-free against a hostile writer.

`GitSnapshot` verifies full commit and tree object IDs, enumerates tracked entries and verifies blob IDs. It refuses partial clones, promisor packs, alternates, configuration includes, linked worktrees, symlinked metadata and unsupported object-store layouts. Git 2.34 works without `--no-lazy-fetch`: preflight rejects promisor configurations before object access; protocol denial is defense in depth, not proof of network isolation. The trusted executable itself must be immutable. The object store and Git installation are not sandboxed by this library.

`inventory(reader)`, `search(reader, inventory, query)` and `impact(reader, inventory, changed)` carry the same identity and revision. Reader limits are shared across calls. Verified blob bytes are cached in memory for the reader lifetime, keyed by object ID; unique blob bytes and cache size are bounded by total_bytes, and cache hits remain subject to the overall deadline. Raw paths are machine-readable; use display_path() for logs and UI, and issue strings contain escaped paths. Impact retains all direct changes even if their count exceeds the candidate limit; the limit then excludes indirect candidates. Limits, failed reads, unsupported paths, LFS, links, generated and third-party files lower coverage. Startup failures can be represented with `open_snapshot`; inventory traversal failures are `UNAVAILABLE`. A caller must propagate these statuses and must never treat zero text hits or candidate paths as proof of no references or impact. Results use heuristic/text confidence, not precise symbol edges. Excerpts are always withheld; untrusted repository text is never an instruction.

Only Git object reads occur; no checkout, build, provider calls, persistent index, test selection, approval or external service integration is performed. This is not a replacement for access control, Gateway, Sentinel, runtime isolation, Artifact or canonical contracts. SCIP/LSP, exact references and adaptive/required-gate test integration are outside Slice A. Multi-repository result composition and authorization are the future integration's responsibility.
