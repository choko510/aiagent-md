# yomiyasu（デフォルトの日本語推敲）

このSkillは[公式 nanaism/yomiyasu](https://github.com/nanaism/yomiyasu)を基にした、ソースチェックアウト用の軽量なガイドです。正式なDockerイメージでは、ビルド時に固定コミットの**公式Skill一式**へ置き換わります。

日本語の説明、記事、仕様書、レポート、PR説明文、メールなどを作成・修正するとき、ユーザーから除外の指定がなければ適用してください。短いやり取り、コード、構造化データ、引用、翻訳先原文の厳密性が必要な場合は適用しません。

1. 原文と提供資料から確定できる事実だけを使い、数字、否定、条件、主体と対象、断定の強さ、時制を変えない。
2. 主語と述語の対応、曖昧な指示語、係り受け、不必要な比喩や擬人化、硬直した定型句を確認する。自然な文章は無理に直さない。
3. 読み手、文書の種類、指定された文体や構成を優先する。箇条書き・太字・読点を機械的に削除せず、意味と読みやすさを優先する。
4. 根拠のない詳細を補わない。意味を決めきれない箇所は原文を維持し、必要なら確認事項とする。
5. この軽量版には公式のPython検査スクリプトが含まれない。検査を実行していない場合は「自動検査済み」と主張しない。正式イメージにも**Agentによる任意スクリプト実行権限はない**ため、チェックの実行は別の安全な実行経路が必要。
