# マーケ・広告・LP・告知コピー

この資料の立ち位置：ブランド指針や媒体の文字数制限・入稿規定がある場合はそちらを優先する。ここはマーケ理論を押しつけるためではなく、AIが書きがちな抽象ポエムや根拠のない誇張を防ぎ、事実ベースで伝わる日本語に整える**裏での補助**として使う。

## 共通のガード
- **熱量や勢いは消さない**：宣伝文や告知の勢いのある語（今すぐ、劇的など、依頼や素材にある温度感）を無理に平らにしない。
- **根拠のない誇張を止める**：No.1・最速・業界初・効果の保証・出所のない数字や比較は勝手に足さない。依頼や素材に根拠がある時だけ使い、裏づけや条件（対象・期間）が必要なら一言確認する。
- **抽象ポエムを普通の動詞と具体に落とす**：「圧倒的な体験を実現」「革新的なソリューション」「シームレスにサポート」のような空虚な語を避け、「誰の、何の手間が、どう変わるか」を普通の動詞で書く（×豊かな生活を実現できます → ○豊かな生活を送れます）。
- **1か所に全部盛りしない**：1つの見出しや広告枠で複数の強みを詰め込まない。いちばん伝えたい1点に絞る。
- **不要な注釈ポエムを足さない**：頼まれていない細かい免責文を勝手に並べない。必要な条件（対象・期限・無料範囲など）だけ読みやすい長さで添える。

## 媒体ごとの要点
- **LP・サービス紹介ページ**：最初の一目で「誰の何が変わるか」を伝え、機能名より結果から書く。行動を促す文やボタンは、過剰な敬語や押し売り口調にしない。
- **広告文・バナー**：文字数制限の中で訴求を1つに絞る。記号や鍵括弧の連打で目立たせず、具体的な悩みか変化で引く。
- **SNS告知・メルマガ**：冒頭の前置きや挨拶を省き、最初の1〜2行で「何のお知らせか」「誰に関係あるか」が分かるようにする。
- **プレスリリース**：事実（いつ・誰が・何を出し、何が違うか）を先に置き、意気込みや評価の言葉と混ぜない。
- **読み物寄りの紹介文**：硬いつなぎ（〜でありながら、〜に仕上がります）は、媒体に合うなら話し言葉（〜なのに、〜が楽しめます）に寄せてよい。
