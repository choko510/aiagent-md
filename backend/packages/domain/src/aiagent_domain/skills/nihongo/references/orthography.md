# 表記・数字・句読点

この資料の範囲：句読点、記号、数字、表記の揺れ。文の組み立ては `craft.md` に置く。

- 同一文書内で表記を統一する。既存の媒体・組織・プロジェクトの表記規則があれば従う。
- 数字は読みやすさと分野の慣習を優先する。指定が無ければ半角で、単位を付ける。日時、金額、割合、単位、バージョンは誤読のない形にする。
- 「事」「為」「出来る」などの漢字/ひらがなは、一般的な現代表記を基本にしつつ、文書の格式・媒体に合わせる。補助的な言葉はひらがなで書く（こと、もの、ため、〜てください、〜ていく、〜てみる、ただし、なお、すでに、ぜひ）。中身のある言葉は漢字で書く（簡単、普通、他の）。機械的なひらがな化はしない。
- 読点は息継ぎの回数ではなく、係り受けや意味の区切りを明確にするために使う。AIの文は短い語句の後に読点を打ちすぎるため、「ないと読み違える所」と「長い前置きの後」にだけ打つ（生成でも推敲でも当てる）。

## 読点の重みと打ち方
読点は、打つ場所に重みを付けて決める。

| 重み | 場所 | 例 |
|---|---|---|
| 必須 | 打たないと読み違える所 | 「私は、泣きながら走る弟を追った」（泣いているのが弟） |
| 必須 | 長い前置き（理由、条件）と本題の境目 | 「スキルを直すたびにテストしたので、時間がかかった」 |
| 中 | 2つの文を「が」「けど」「ので」でつないだ所 | 「疲れたけど、楽しかった」 |
| 中 | 並べた語が3つ以上の時 | 「メール、LINE、お知らせ」 |
| 中 | 定型の前置きの後 | 「お手数ですが、」 |
| 低 | 短い主語や話題の後 | 「今日は、」「私は、」 |
| 低 | 文頭の接続詞の後 | 「でも、」「なので、」 |
| 低 | 短い時や場所の言葉の後 | 「昨日、」「駅で、」 |

- **打たない所**：「を」の後、修飾語とそれがかかる語の間（いつも、最後まで）、短い文の文頭の短い語句の後（今日は、昨日、駅で、右上から、）。硬い文書でも短い主語や話題の後には打たない（×原因は、設定の誤りです）。
- **例外として打つ／残す所**：短い文でも「1つ目は、」「三つ目は、」のような順番の言葉の後、「〜するまでは、」のように動詞を含む部分の後、後ろに「〜してから」「〜たら」が続く部分の前は打つ。お知らせやメールの定型の前置きは残す。宣伝文で語を立てたい時の「〜を、」も残してよい。
- **場面ごとの目安**：
  - 友達とのLINEやチャット：必須だけ打つ。中は文が長い時だけ。低は基本打たない（ただし話し始めの「で、」「てか、」のように声に出すと間が空く所は打ってよい）。
  - 返事、メール、ブログ：必須と中を打つ。低は文が長くて読みにくい時だけ。
  - お知らせ、正式文書、技術文書：必須と中を打つ。低は基本打たない（×データベースには、PostgreSQLを採用します ×原因は、設定変更と推定しています）。
- どの場合も、1文に読点が3つ要る（3つを超える）時は、文を分けられないかを先に考える。
- 書き言葉の「は」の後は、打たないことの方が多い。打つかどうかは、文の長さ、その文の他の読点、段落の1文目かどうかが重なって決まる。1つの条件だけで決めない。会話やLINEには当てない。
- **仕上げと推敲**：読点は打たずに書き始め、要る所にだけ足す。書き終えたら読点を1つずつ外してみて、外しても読み違えないなら外す（特に文頭の「〜は」「〜で」「〜から」「〜までに」「〜とは」の後と、「を」の後を見る）。推敲では原文の読点が要らない所にあれば外し、直したのが読点だけでも直す理由になる。
- **スクリプト連携**：Pythonが使える時は、`python3 <このスキルのフォルダ>/scripts/trim_commas.py 書いた文.md 読点を直した文.md` を実行し、短い文の頭の語句の後と「を」の後の読点だけを外す。推敲で意味ズレ検査とまとめて行う時は `scripts/cli.py fix 原文.md 直した文.md 出力.md`（または `revert_broken.py` の後に `trim_commas.py`）を使う。スピーチや読み上げの原稿には使わない（読点が息継ぎの印になるため、`cli.py fix` では `--no-trim-commas` を付ける）。

例（どれも合成）：
- 短い文の頭
  - 前：昨日は、駅前の本屋で新しい料理の本を買った。
  - 後：昨日は駅前の本屋で新しい料理の本を買った。
  - 理由：短い文なので、「昨日は」の後で切らなくても読める。
- 「を」の後
  - 前：会議の資料を、明日までに送ってください。
  - 後：会議の資料を明日までに送ってください。
  - 理由：「を」の後で切ると、そこで話が終わったように読める。
- 修飾語の途中
  - 前：父は、毎朝、必ず六時に起きる。
  - 後：父は毎朝必ず六時に起きる。
  - 理由：どの読点も、無くても読み違えない。
- 案内や通知の文
  - 前：お支払いは、来月の10日までにお願いします。
  - 後：お支払いは来月の10日までにお願いします。
  - 理由：硬い文でも、短い文の頭の「〜は」の後は要らない。
- 打つ所は残す
  - 前：雨が強くなってきたので早めに切り上げたが駅に着く前にずぶ濡れになった。
  - 後：雨が強くなってきたので早めに切り上げたが、駅に着く前にずぶ濡れになった。
  - 理由：長い前置きと結果の境目には、読点が要る。

## 記号と表記の細部
- 括弧、かぎ括弧、ダッシュ、コロン、三点リーダーを装飾的に多用しない。必要な機能がある場合は使う。
- 横書きでは、括弧と「！」「？」は全角にする。英数字と日本語の間に空白を入れない（周りの文書が入れていれば合わせる）。
- 英数字・記号・全角半角は、媒体や技術仕様に合わせる。コード、識別子、URLは原文どおり保持する。
- 表記の揺れを直す際は、固有名詞・公式名称・引用文を勝手に変更しない。
- 日付と曜日、時刻などが食い違っている時は、正しい方を勝手に選ばず、食い違いを伝える。
