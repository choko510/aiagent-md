# Personal Profile（`~/.nihongo/profile.md` のひな形）

このファイルはスキルフォルダ内のひな形であり、スキルの更新で上書きされる。ふだんはホーム配下の **`~/.nihongo/profile.md`** にコピーして使うか、自分の文を貼って「私の書き方を覚えて」と頼んで自動作成する（すでに `CLAUDE.md` や `AGENTS.md` に「私の書き方」メモがある場合はそちらも尊重される）。

## 使い方の決まり

- **対象**：本人名義の文（LINE・メール・SNS・ES・作文・ブログ等）にだけ使う。技術文書と AI 自身の返答には使わない。
- **Anti-Voice（`絶対に言わない表現`）**：自分が絶対に書かない表現（過剰な敬語、カタカナ語、絵文字連打など）を並べるのが、自分らしさを出す一番の近道。ここに書いた表現は `cli.py diff` / `cli.py git --profile ~/.nihongo/profile.md` で機械的にも検査できる。
- **場面の境界（フェイルセーフ）**：`[casual]` の崩しや絵文字は `[formal]` へ絶対に持ち込まない。相手や場面が曖昧な時は、安全な側（`[work]` または `[formal]`）へ倒す。
- **透明な管理**：黙って書き換えることはしない。いつでも「書き方メモ見せて」「`[casual]` の〇〇消して」と指示して確認・削除できる。
- **個人情報禁止**：実名・会社名・メールアドレス・電話番号などの個人情報は絶対に書かない。

## 標準フォーマット（`~/.nihongo/profile.md`）

見出し（`## [common]` / `## [casual]` / `## [work]` / `## [formal]`）と `- 絶対に言わない表現：` 行は `cli.py --profile` でも読み取るため、名前を変えずに使う。

```markdown
# 私の書き方

## [common]
- 一人称：
- 絶対に言わない表現：
- 書く時の考え方：

## [casual]
- 場面：友達・身内・雑談
- 口調・記号：

## [work]
- 場面：社内チャット・PR・同僚
- 口調・記号：

## [formal]
- 場面：目上・社外メール・公式お知らせ（[casual] の崩しや絵文字は持ち込まない）
- 口調・記号：
```

## 記入例（参考）

```markdown
# 私の書き方

## [common]
- 一人称：私
- 絶対に言わない表現：「〜させていただきます」「恐れ入りますが」「アサイン」「コミット」、絵文字の連打
- 書く時の考え方：結論を1文目に置き、前置きや余計なクッション言葉を省く

## [casual]
- 場面：友達・身内・雑談
- 口調・記号：常体寄り、「〜だね」「〜かな」。誘う文だけ「！」を1つ

## [work]
- 場面：社内チャット・PR・同僚
- 口調・記号：フラットな「です・ます」。了解は「了解です」と短く返す

## [formal]
- 場面：目上・社外メール・公式お知らせ（[casual] の崩しや絵文字は持ち込まない）
- 口調・記号：標準的な敬語。過剰にへりくだらず簡潔に締める
```

詳しい作り方（会話学習・3問クイック作成・過去の文3〜5通からの分析）は `references/make-profile.md` を参照する。
